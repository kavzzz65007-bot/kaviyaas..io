Independent hackathon project. Not affiliated with, endorsed by, or connected to AICTE or the official APAAR portal. The logo is shown for context only. All demo data is synthetic.

The problem

Institutions prepare large student datasets before uploading them to an authorized academic portal. Missing fields, malformed dates, duplicate identifiers and inconsistent values are usually found only after upload, causing rework and delays.

The solution

We don't replace the official APAAR portal. We help institutions identify and correct data-quality issues before uploading student records to it.

Every finding is explained, comes with a suggested action, and stays under human control.

Core capabilities

Mandatory & format checks

Configurable required fields, date validation and identifier patterns. Original values are never destroyed.

Duplicate detection

Exact duplicates plus fuzzy name similarity (suggestions only - never auto-merged or deleted).

Cross-field rules

Admission year versus academic year, age at admission and unusual-pattern review flags.

Document text comparison

Compare pasted or extracted document text with record fields. A match is not proof of authenticity.

Transparent quality score

A weighted 0-100 data-quality indicator with visible dimensions. Not an official verification score.

Audit & exports

Every action is logged. Export corrected datasets and detailed issue reports as CSV or XLSX.

How it works

  1. 1

    Upload

    Drop a CSV/XLSX file or load the synthetic demo set.

  2. 2

    Map & preview

    Confirm how your columns map to canonical fields.

  3. 3

    Validate

    Run the rule engine and review explained findings.

  4. 4

    Correct & re-run

    Fix values, record decisions, re-validate and compare runs.

  5. 5

    Export

    Download the corrected dataset and issue reports.

Security & privacy

  • Role-based permissions (Administrator, Data Entry Staff, Reviewer)
  • All output is HTML-escaped; exports are protected against spreadsheet formula injection
  • Audit log of corrections, reviews, validations and exports
  • Synthetic data only; no third-party AI or network calls for validation

Honest limitations

  • No connection to the official APAAR portal
  • Missing APAAR IDs are never guessed or generated
  • Text matching does not authenticate a document or an identity
  • This demo runs in your browser; production use needs a secured server backend
